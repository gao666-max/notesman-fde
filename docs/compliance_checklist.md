## 关键设计决策

### 编辑可修改 vs AI 直接判断

不同编辑对"什么值得写、如何组织、哪些表述需核实"的判断不一致。我们的设计是：

- **AI 建议，编辑决策**：Agent 1 提取观点并给出置信度/热点标注，编辑通过拖拽决定用哪些、如何排序
- **标题可编辑**：Agent 1 建议标题，编辑在顶部输入框随时修改
- **章节可重组**：Agent 1 建议段落结构，编辑可拖拽卡片到不同章节、调整顺序
- **草稿是起点不是终点**：Agent 3 生成的文章是 v0.5，编辑在此基础上修改

### 目标读者/渠道/时效的体现

当前原型中通过以下方式体现：
- Agent 1 的 Prompt 中指定了目标读者（创业者、管理者、职场人士）
- Agent 3 的 Prompt 中约束了笔记侠公众号风格
- 方案设计中规划了"编辑在导入前选择目标读者/渠道"的前置步骤
